# Галерея «Наши места»

Постройки хранятся в `gallery.json`, картинки — в папке `images/`. Сайт перечитывает `gallery.json` сам, как только файл
меняется: перезапускать ничего не нужно.

## Как добавить постройку

1. Сохраните скриншот в `images/`. Имя файла — латиница, цифры, `-`, `_`, `.`; формат `.webp`, `.avif`, `.jpg` или `.png`.
   Лучше всего `.webp` шириной около 1600 px — такая картинка весит 150–300 КБ.
2. Добавьте запись в массив `items`:

```json
{
  "id": "house-by-the-lake",
  "title": "Дом на берегу",
  "author": "PlayerName",
  "description": "Первый дом на сервере, с причалом и маяком.",
  "image": "house-by-the-lake.webp",
  "coords": { "x": 123, "y": 70, "z": -456 },
  "addedAt": "2026-09-16"
}
```

| Поле | Обязательно | Правила |
|---|---|---|
| `id` | да | уникальный, латиница в нижнем регистре, цифры и `-`, до 64 символов |
| `title` | да | до 80 символов |
| `author` | да | ник, до 32 символов |
| `description` | нет | до 400 символов |
| `image` | да | имя файла из `images/` |
| `coords` | да | целые `x`, `y` (от −64 до 320), `z` — координаты из F3 |
| `addedAt` | нет | дата в формате `ГГГГ-ММ-ДД` |

Записи с ошибками сайт пропускает и пишет причину в лог (`journalctl -u our-server-site`), остальная галерея продолжает
работать.

Конвертировать скриншот в WebP можно так: `cwebp -q 82 -resize 1600 0 screenshot.png -o images/house-by-the-lake.webp`
(пакет `webp` в Ubuntu).
