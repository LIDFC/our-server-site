# Our Server — сайт Minecraft-сервера

Официальный сайт сервера `mc.vin-off.site` (Paper, Minecraft 1.21.11). Человек, который впервые зашёл на сайт, за пару
минут узнаёт, работает ли сервер, скачивает [наш лаунчер](https://github.com/LIDFC/MkeiitLauncher) и заходит в игру.

- **Главная** — живой статус сервера (онлайн, игроки, версия, отклик), адрес с копированием, кнопка загрузки лаунчера под
  систему посетителя, превью карты, доска почёта, онлайн за сутки.
- **Лаунчер** — зачем он нужен, все сборки из последнего релиза GitHub с объяснением различий, пошаговая инструкция.
- **Карта** — squaremap во встроенном окне; пока карта не настроена, сайт честно об этом пишет.
- **Статистика** — итоги сервера, доски почёта, «кто был первым», график онлайна за 24 часа и 7 дней, таблица игроков.
- **Галерея** — постройки со скриншотом, автором, координатами и кнопкой «Показать на карте».
- **Правила** — правила и частые вопросы: AuthMe, Simple Voice Chat, подключение, лаунчер.

Все данные настоящие: статус спрашивается у Minecraft-сервера, статистика читается из файлов мира, версия лаунчера — из GitHub
API. Если источник недоступен, сайт так и пишет, а не показывает выдуманные цифры.

## Превью

Дизайн «глубинный сланец и фонарь»: графитовый фон, один тёплый янтарный акцент, зелёный — только для статуса «в сети».
Панель статуса на главной светится, как фонарь, и чем больше людей на сервере, тем ярче. Шрифты Onest и JetBrains Mono
(только для адреса, команд и координат) хранятся на самом сайте.

Чтобы посмотреть сайт с демо-данными, выполните шаги из раздела «Запуск локально».

## Стек

| Часть | Что | Почему |
|---|---|---|
| Фронтенд | [Astro](https://astro.build) 7, статическая сборка, TypeScript без фреймворка | готовый HTML, на странице один небольшой скрипт; никакого React ради пары виджетов |
| Бэкенд | Node.js 24, встроенный `http`, **ни одной runtime-зависимости** | около 70 МБ памяти; Node 24 запускает TypeScript сам, без шага сборки |
| Данные | файлы мира Minecraft, JSON-файл истории онлайна | для 10 игроков база данных не нужна |
| Карта | squaremap (плагин Paper) | заметно легче BlueMap |
| Прокси | nginx + Let's Encrypt | HTTPS, gzip, второй домен для карты |

## Запуск локально

Нужен Node.js 24 или новее.

```bash
npm ci
cp .env.example .env
node scripts/dev-fixtures.mjs
```

В `.env` для локальной проверки укажите:

```ini
TRUST_PROXY=false
MC_HOST=mc.vin-off.site          # живой статус настоящего сервера
MC_SERVER_DIR=.dev/minecraft     # демо-статистика из dev-fixtures
DATA_DIR=.dev/data
GALLERY_DIR=.dev/gallery
```

`scripts/dev-fixtures.mjs` создаёт в `.dev/` вымышленных игроков, историю онлайна и картинки галереи. Эта папка игнорируется
git и на сервере не используется.

- `npm run dev` — сервер API на `:3000` и Astro с горячей перезагрузкой на http://127.0.0.1:4321 (запросы `/api` и `/media`
  проксируются на API);
- `npm run build && npm start` — production-режим на http://127.0.0.1:3000, как на VPS.

## Сборка и проверки

```bash
npm run typecheck   # типы бэкенда
npm test            # 47 тестов: протокол, опрос сервера, статистика, история, релизы, галерея, HTTP, API целиком
npm run build       # статический сайт в dist/
npm run check       # всё сразу
```

## API

Все ответы — JSON, только `GET`, общий лимит запросов на IP.

| Эндпоинт | Что отдаёт | Кеш |
|---|---|---|
| `GET /api/server/status` | онлайн, игроки, версия, отклик, время проверки | 15 с на сервере |
| `GET /api/server/players` | число игроков, максимум и ники (Server List Ping отдаёт до 12) | 15 с |
| `GET /api/server/stats` | статистика каждого игрока, итоги, «кто был первым» | 5 мин |
| `GET /api/server/leaderboard` | топ-5 по категориям и события мира | 5 мин |
| `GET /api/server/online-history?hours=24` | точки `[время, игроки]`, `-1` — сервер был выключен; `hours` от 1 до 168 | — |
| `GET /api/gallery` | постройки галереи | до изменения файла |
| `GET /api/launcher/release` | последний релиз лаунчера с разобранными сборками | 10 мин |
| `GET /api/config` | публичные настройки: адрес, ссылка на карту | — |
| `GET /api/health` | `{ "ok": true }` для мониторинга | — |

Абсолютные пути сервера, UUID игроков и токены в ответы не попадают.

## На будущее

- **Админка галереи.** Галерея читается через интерфейс `GalleryStore` (`server/src/services/gallery.ts`). Хранилище с
  загрузкой через панель — это вторая реализация того же интерфейса, страницы менять не придётся.
- **Новые категории статистики** добавляются одной строкой в `LEADERBOARD` и `MILESTONES` (`server/src/services/stats.ts`).
- **Полный список игроков.** Если на сервере включить `enable-query`, его можно добавить в `services/status.ts` — формат
  ответа API уже различает полный и частичный список (`playerListComplete`).
